# Low Plat

Минималистичный браузерный платформер: куб, прыжки, скольжение по стенам и отскоки от них.
Играть: скачать **один файл** `dist/low-plat.html` и открыть его в браузере (двойной клик). Зависимостей нет.

`index.html` — версия для разработки, она подключает `src/*.js`, поэтому одна без папки `src` не работает.
После правок в `src/` пересобрать единый файл: `node tools/build.js`.

## Управление
- `← →` / `A D` — бег, `Пробел` / `↑` / `W` — прыжок
- зажать направление в сторону стены в воздухе — держишься и медленно скользишь; не зажимать — падаешь
- прыжок у стены — отскок от неё
- `R` — начать уровень заново, `[` `]` — предыдущий/следующий уровень

## Устройство
- `src/sim.js` — физика (без DOM), `src/levels.js` — уровни, `src/main.js` — отрисовка/ввод/цикл
- Уровень — набор прямоугольников `['#' | '^' | '.', x, y, w, h]` на поле 32×18 тайлов
- `node tools/solve.js [N] [--map]` — проверяет, что уровни проходимы (BFS по настоящей физике)

## Производительность
Уровень рисуется в offscreen-канвас один раз; в кадре перерисовывается только область вокруг куба.
Фиксированный шаг 60 Гц, нет аллокаций в цикле, фоновая вкладка не тратит CPU. Код — ES5.
